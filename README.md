# Mustafa Sultan — Portfolio

React, TypeScript, and Vite portfolio website.

## Local development

```powershell
npm install
npm run dev
```

Open the local URL printed in the terminal. Generate the production site with `npm run build`.

## Directory layout

- `src/components/` — website sections and reusable UI components.
- `src/data/` — portfolio content and navigation.
- `src/index.css` — shared theme and layout styles.
- `public/images/` — photos used by the website.
- `public/certificates/` — certificate images used by the website.
- `public/mustafa_sultan_resume.pdf` — downloadable résumé; its public URL is preserved.
- `source-assets/` — original photos, résumé, and supplied certificate files.
- `docs/design/` — design reference images.
- `archive/legacy-build/` — preserved files from the older compiled website.
- `dist/` — production output generated by Vite; do not edit by hand.
- `.github/workflows/` — GitHub Pages deployment workflow.

## Updating content

Edit `src/data/portfolioData.ts` for experience, projects, personal details, and credentials. Put website images in `public/images/` and certificates in `public/certificates/`, then update the corresponding paths. Retain original supplied files in `source-assets/` when useful.

To update the downloadable résumé, replace `public/mustafa_sultan_resume.pdf`. Files in `source-assets/` are reference material and are not automatically published.

The GitHub Pages workflow builds and deploys `dist/` when changes are pushed to `main`.
